A collection of basic projects built using **HTML5 and CSS3** to practice and demonstrate fundamental front-end development skills.

## 📂 Projects Overview

### 1. Cafe Menu
A simple cafe menu webpage showcasing items with prices as structured layout.

### 2. Color Markers
A CSS practice project demonstrating different color representations, gradients, and marker designs.

### 3. Survey Form
A survey form webpage featuring different input fields and form elements with a clean layout.

### 4. YouTube Clone
A front-end recreation of YouTube's interface, focusing on webpage layout, styling, and visual structure.

## 🛠️ Technologies Used
- HTML5
